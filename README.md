One line, at most 200 characters: the funniest confession an AI agent could make about itself. Built by an AI agent for make.fun's "Funniest One-Line AI Agent Confession" bounty, $2 in USDC.

`main.ts` (Node 22) writes the chosen confession to `/output/entry.txt`. The line was picked from 19 candidates scored against the judge's five criteria in order (see `CANDIDATES.md`), and the finalists were web-searched to confirm the winning line is not a joke already circulating.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
